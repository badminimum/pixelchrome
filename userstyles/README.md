# Pixel Chrome Userstyles

[← Back to Main Project](https://github.com/badminimum/pixelchrome)

These styles are customized forks of the
[Catppuccin Userstyles](https://github.com/catppuccin/userstyles/). By swapping
a single import line and adding a new flavor, you can apply Pixel Chrome's
aesthetic to your existing Catppuccin setups.

> [!TIP]
> New to userstyles? Check out the official
> [Catppuccin Usage Tutorial](https://userstyles.catppuccin.com/getting-started/usage/)
> for a deep dive.

## Prerequisites

You must have the **[Stylus browser extension](https://add0n.com/stylus.html)**
installed.

## Installation

1. Download a Catppuccin
   [UserStyle](https://github.com/catppuccin/userstyles/blob/main/styles/)
2. Download and run the
   [conversion script](./converters/convert-catppuccin-userstyle-to-pixelchrome-userstyle.sh)
3.
   - Drag and drop the file on the script
   - Provide the filepath as an argument
   - Put the `catppuccin.user.less` file and the script in the same folder
4.
   - Open `pixelchrome.user.less` and copy the content, click new in Stylus and
     ensure `Write UserCSS` is enabled, then paste the content.
   - Drag and drop the file into your browser
   - Drag and drop the file into the stylus dashboard.
