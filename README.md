# Pixel Chrome

Pixel Chrome is a monochrome theme available for multiple platforms. The color palette is taken from [Monochrome KDE by PWYDE](https://github.com/pwyde/monochrome-kde), which is why this repository is licensed under GPL-v3.

This project is not purely based on Catppuccin. However, the `userstyles` directory contains customized forks of Catppuccin userstyles[cite: 2]. That directory includes a custom palette library (`pixelchrome.lib.less`)[cite: 1] and a conversion script (`convert-catppuccin-userstyle-to-pixelchrome-userstyle.sh`) to apply the Pixel Chrome aesthetic to existing Catppuccin setups[cite: 2, 3].

If you are looking to install or modify the web userstyles, please refer directly to [`userstyles/README.md`](./userstyles/README.md)[cite: 2].
